Обязательно для работы программы нужно создать файл "config.json" (если его нет), там находятся главные настройки!

Следующие настройки в файле "config.json":
{
  "API_KEY": "Поставить свой ключ",
  "city": "Имя города",
  "url": "https://api.weatherapi.com/v1/current.json",
  "lang": "ru",
  "debug": "False",
  "interval": 1,
  "mode": "interval",
  "exact_time": "9:00"
}

после версии 0.1 удалено .exe из за того что много весит, но можно через pyinstaller открыть файл code.spec 

Если в строке debug ввести значение "True" включаться "программное" сообщение в том же окне где и открыто
